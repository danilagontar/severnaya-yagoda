# Северная ягода — проверка счетов поставщиков

Пилот для кейса 04 Navicon AI Fest 2026. Разбирает письма из ящика бухгалтерии, сверяет счёт с заказом (1С:ERP), согласованиями (Directum RX) и приёмкой и выдаёт вердикт: оплатить / вопрос / вернуть / дубль / стоп / письмо — с суммой к оплате, правилом П-1…П-9 и адресатом вопроса.

Суммы и вердикты считает детерминированный код (`src/core`). LLM (GigaChat, необязательно) только извлекает поля из текста письма и переписывает черновики писем; всё, что она вернула, проверяется по исходному тексту.

## Запуск

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm test       # эталон 25/25 + новые письма
pnpm build      # проверка типов и сборка в dist/
```

Если данные кейса изменятся: `pnpm data` пересоберёт `src/data/case.json` из `data/Данные_к_кейсу_04.xlsx`.

## Что где

| Путь | Что |
|---|---|
| `src/core/extract.ts` | извлечение полей из письма правилами |
| `src/core/reconcile.ts` | сверка и вердикты, сводка |
| `src/core/drafts.ts` | черновики писем закупщику, поставщику, складу, казначею, ФД |
| `src/core/etalon.ts` | эталон (data/case04_etalon.md) в виде данных |
| `src/core/*.test.ts` | автотесты |
| `src/llm/provider.ts`, `server/` | подключение GigaChat (docs/llm.md) |
| `src/components/` | интерфейс |
| `docs/` | палитра, решения, LLM |

## Экраны

- **Очередь** — документы сгруппированы по действию; карточка с таблицей «Заказ / Согласование / Приёмка / Счёт». Наведение на ячейку счёта подсвечивает фрагмент письма, откуда взято число.
- **Новое письмо** — вставить письмо жюри; очередь пересчитывается целиком, баннер показывает, у каких документов сменился вердикт.
- **Реестр** — к оплате с итогом и CSV, отдельно «не включено в реестр» с причинами.
- **Проверка на эталоне** — 25 документов против ручной разметки.

Решения, принятые командой, — `docs/decisions.md`.

## Выкладка на Vercel

- Сайт собирается командой `pnpm build` в `dist/`, ИИ работает через серверную функцию `api/llm/[action].ts` (тот же код, что прокси в `pnpm dev`).
- Ключ ИИ в выгрузку не попадает (`.vercelignore`). Чтобы ИИ работал на сайте, в настройках проекта на Vercel → Settings → Environment Variables задать:
  `LLM_MODE=gigachat`, `GIGACHAT_AUTH_KEY=<ключ>`, `GIGACHAT_SCOPE=GIGACHAT_API_PERS`, `GIGACHAT_MODEL=GigaChat-2-Max` — и сделать redeploy.
- Без ключа сайт работает на правилах.
- Серверы Vercel за рубежом; доступен ли с них GigaChat API — проверяется после выкладки.
