## Правила применения

- Вердикт никогда не передаётся только цветом: всегда текст + значок. «Вернуть» и «стоп» близки по тону.
- «Стоп» единственный вердикт со сплошной заливкой, у остальных цветной текст на подложке 10–15 % того же цвета.
- Акцент только для логотипа и главной кнопки, не статусы (близок к «стопу»).
- Цифры: моноширинные (tabular-nums), по правому краю, разряды через неразрывный пробел.
